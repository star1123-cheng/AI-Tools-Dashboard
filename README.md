## 🚀 核心功能與最新優化特點

### 1. 純淨半透明膠囊浮水印（依需求完成修改）
* **徹底移除綠色背景底色**：不再調用帶有綠底邊角的 PNG 圖片，改採原生現代 CSS 玻璃擬態（Glassmorphism）打造。
* **字體飽滿放大**：字級調整為 `1.05rem` 粗體白字，閱讀清晰。
* **平面 2D 無立體陰影**：移除所有 3D 浮凸、投影（Drop Shadow）與縮放晃動，呈現純粹平面的圓角膠囊（`Created by 祐誠老師`），半透明不遮擋畫面。

### 2. 六大分類嚴格互斥比對（Strict Category Filtering）
* 點擊任何分類 Tab，**100% 嚴格僅顯示該分類的工具**，絕無跨類別污染。
* **資料庫全量統計（共 120 款教育工具）**：
  1. **🌐 自製網站**（**3 筆**）：祐誠老師親自開發的 GitHub 專案（*英語大冒險*、*Class 602 班親會太空艙*、*大電視觸控雙人拔河對戰遊戲*）。
  2. **🛠️ 一、綜合教學資源地圖與平台**（**16 筆**）
  3. **📚 二、學科教材、特教與專業學習資源**（**24 筆**）
  4. **📝 三、測驗評量、審題與課堂管理**（**23 筆**）
  5. **🎨 四、創意生成、提示詞與趣味遊戲**（**22 筆**）
  6. **📂 五、行政、評語與 NotebookLM 進階工具**（**32 筆**）
  *(3 + 16 + 24 + 23 + 22 + 32 = 120 筆，數量完全閉環)*

### 3. 熱門快篩智慧全域穿透（All-Tag Search）
* 點擊下方任一「熱門快篩」按鈕時，系統自動切換至全庫檢索模式，保證每一項點擊都有滿滿的實用工具：
  * `Gemini`（23 款）、`NotebookLM`（33 款）、`評語生成`（32 款）、`特殊教育`（26 款）、`學習單`（3 款）、`班級經營`（6 款）、`遊戲化學習`（24 款）、`測驗審題`（23 款）、`提示詞庫`（35 款）、`學校行政`（33 款）、`試算表/GAS`（9 款）、`Canva`（7 款）。
* 再次點擊同一標籤即可一鍵取消快篩。

## 🌙 深淺雙模與常用功能

1. **主題切換**：右上角點擊 🌙 / ☀️ 即可切換深色科技風與淺色清新風，喜好設定自動保存於瀏覽器 `localStorage`。
2. **星號收藏**：點擊卡片右上角星號（★），即可將日常最常用的備課工具加入收藏，並支援「我的收藏優先排序」。
3. **視圖切換**：支援「▦ 網格卡片視圖」與「☰ 緊湊清單視圖」。
4. **資料匯出**：右上角可隨時將整理好的 120 筆工具一鍵匯出為乾淨的 `JSON` 或 `CSV` 檔案。
